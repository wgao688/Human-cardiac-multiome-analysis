### Binarized diseased DEG analysis


### STEP 1: Obtain disease DEGs
Using this script `01_run_pydeseq2_disease_binary.py` which calls functions from `run_pydeseq2_plots.py`.

### STEP 2: Extract the DEGs
Using this script `02_extract_disease_DEGs.ipynb`

### STEP 3: Generate volcano plots
Using this script `03_generate_volcano_plots_in_R.ipynb`

### STEP 4: Examine DEG similarity across cell types
Using this script `04A_extract_num_DEGs_for_covariate.ipynb`. Visualize using `04B_visualize_DEG_similarity_across_cell_type.ipynb`.
